# Lyra 0.9.0 — Tabs, polish, and bugfixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship post-0.8.0 fixes and Obsidian-style window tabs: reliable sidebar hit-testing/rename, Settings resize and humanized prefs, appearance System↔Light fix, status bar polish, remove detail Open Vault / title “Lyra”, shared-vault tabs with empty-tab actions and note titles.

**Architecture:** Keep **one vault store per window**. Replace “one editor per window” with **N note tabs** sharing that store and sidebar. Appearance forces `NSApp` + per-window `NSAppearance` and stops fighting `.preferredColorScheme` when preference is System. Settings becomes a resizable scene (or falls back to a regular Settings window with `windowResizability`).

**Tech Stack:** SwiftUI + AppKit, `@Observable`, `@AppStorage`, no new packages.

- [ ] **Step 1: Strengthen `AppearanceController`**

```swift
enum AppearanceController {
    static func apply(_ preference: AppearancePreference) {
        let appearance: NSAppearance?
        switch preference {
        case .system: appearance = nil
        case .light: appearance = NSAppearance(named: .aqua)
        case .dark: appearance = NSAppearance(named: .darkAqua)
        }
        NSApp.appearance = appearance
        // Critical: clear sticky window-level overrides when returning to System
        for window in NSApp.windows {
            window.appearance = appearance
        }
    }
}
```

#### Behaviors (match user + Obsidian-ish)

| Action | Result |
|--------|--------|

| New Tab (`+` or ⌘T) | Empty tab; **sidebar stays** with same vault |

| Close tab | Close empty or close note (save first); last tab close → empty tab remains (don’t destroy vault) |
| Tab bar layout | Tabs grow **left → right**; **`+` after last tab** (not alone on the far right of the window) |

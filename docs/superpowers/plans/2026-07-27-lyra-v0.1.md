# Lyra v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a native macOS Markdown vault editor scaffold: AI-ready open-source repo, open a folder as a vault, file tree, edit `.md` with basic highlight + live preview, autosave, CRUD, and `[[wiki links]]`.

**Architecture:** Single Xcode macOS app target with module-shaped folders (`App/`, `Vault/`, `Editor/`, `Preview/`, `Models/`). Disk is source of truth (plain `.md`). `@MainActor` stores + async file I/O. TextKit 2 editor preferred; native Markdown preview via `AttributedString` / swift-markdown; no database.

**Tech Stack:** Swift 5.10+, SwiftUI, AppKit (TextKit), Foundation `FileManager`, macOS 15+, Xcode project, MIT license.

## Global Constraints

- Platform: macOS only; deployment target **macOS 15.0**
- Bundle ID: **app.lyra.Lyra**
- Packaging: **Approach A** — one Xcode app target; no `Package.swift` in v0.1
- Data: plain UTF-8 `.md` files only; no SQLite / lock-in formats
- Sandbox: on, user-selected files read/write + security-scoped bookmarks
- License: MIT (existing `LICENSE`, © Jack Spiering)
- YAGNI: no plugins, graph, sync, tags DB, iOS, Electron
- Prefer small files, one primary type per file
- Commits: small and reviewable after each task
- Full compile requires a Mac with Xcode; pure logic tests may not run on Linux CI
- Spec: `docs/superpowers/specs/2026-07-27-lyra-v0.1-design.md`

- [ ] **Step 2: Implement `UntitledName`**

```swift
import Foundation

enum UntitledName {
    static func next(in directory: URL, fileManager: FileManager = .default) -> String {
        let base = "Untitled"
        let ext = "md"
        var candidate = "\(base).\(ext)"
        var n = 2
        while fileManager.fileExists(atPath: directory.appendingPathComponent(candidate).path) {
            candidate = "\(base) \(n).\(ext)"
            n += 1
        }
        return candidate
    }
}
```

- [ ] **Step 3: Implement `WikiLinkResolver`**

Rules: strip optional surrounding whitespace; strip optional trailing `.md`; case-insensitive match on `deletingPathExtension().lastPathComponent`; first match in provided `noteURLs` wins.

```swift
import Foundation

struct WikiLinkResolver {
    private let notesByStem: [String: URL]

    init(noteURLs: [URL]) {
        var map: [String: URL] = [:]
        for url in noteURLs {
            let stem = url.deletingPathExtension().lastPathComponent.lowercased()
            if map[stem] == nil { map[stem] = url }
        }
        self.notesByStem = map
    }

    func resolve(_ linkText: String) -> URL? {
        var name = linkText.trimmingCharacters(in: .whitespacesAndNewlines)
        if name.lowercased().hasSuffix(".md") {
            name = String(name.dropLast(3))
        }
        return notesByStem[name.lowercased()]
    }
}
```

- [ ] **Step 4: Implement `FileSystemVault` helpers**

`shouldInclude`: return `false` if `name == ".DS_Store"` OR `name == ".git"` OR `name.hasPrefix(".")`.

`scan(root:)`: build a directory `VaultNode` whose children are included subdirectories (recursive) and files with `pathExtension.lowercased() == "md"`, sorted by name (case-insensitive).

`readUTF8` / `writeUTF8`: `String(contentsOf:encoding:)` / `write(to:atomically:encoding:)`.

CRUD: create empty file / create directory / `moveItem` for rename / `trashItem` for delete.

- [ ] **Step 5: Write unit tests**
